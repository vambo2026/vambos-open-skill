## human-centered-ui

适合新建网站、产品页面、工作台，或改善“AI 感太重”的界面。主要流程：

1. 编码前说明视觉方向、信息顺序、组件边界和交互。
2. 让内容决定布局，不预设所有项目都是营销页或卡片宫格。
3. 减少缺乏用途的装饰，同时保留符合项目气质的表达。
4. 让交互真实可用，明确区分正式内容、原型与计划。
5. 检查实际桌面和手机截图，再交付。

“减少 AI 感”不等于统一改成白底极简，也不保证任何固定风格都适合所有用户。

### 使用

支持 AgentSkills 的工具：将 `skills/human-centered-ui` 目录安装到该工具文档指定的技能目录。不同工具的技能路径与启用方式不同，请遵循各自文档。

不支持技能自动加载的工具：直接提供 [SKILL.md](skills/human-centered-ui/SKILL.md) 的内容作为本次页面开发的设计要求。

示例请求：

> 使用 human-centered-ui 设计这个页面。先结合我的内容解释视觉与布局选择，再实现并检查桌面、手机截图。避免无意义口号、装饰和空白，不要把所有区块套成相同卡片。

发布到这个仓库不意味着自动安装或启用到任何本地 AI 工具。
